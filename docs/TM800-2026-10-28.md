# TM800 실제 패킷 수신 · 30초 관제

2026-10-28 적용. 이전 문서의 JSON/폼 전송 외에 실제 text/plain 패킷도 지원합니다.

## 단말기 설정

1. POST 수신 주소를 `https://lte-gps-map.vercel.app/radlot/data`로 변경합니다. 기존 trycloudflare 주소로 보내면 이 사이트에는 전달되지 않습니다.
2. `Content-Type: text/plain`을 사용합니다.
3. `X-GPS-Key: 실제 GPS_WRITE_KEY` 헤더를 추가합니다. 헤더 설정이 불가능하면 주소 끝에 `?key=실제_GPS_WRITE_KEY`를 붙입니다. 실제 키는 별도 전달된 GPS 전송키 파일의 값입니다. 관리자 키와 다릅니다. 키를 GitHub에 올리지 마세요.
4. 본문 예시:

```text
l450061222243141|TEST=1|KST=20261028170635|LAT=35.176583|LON=129.125880|MODE=1|ERR=0
```

5. 단말기 펌웨어에서 30초마다 현재 GPS 좌표를 읽어 전송합니다. 서버의 조회 주기는 단말기 전송 주기를 변경하지 않습니다.
6. HTTP 200 및 JSON `ok:true`를 확인합니다. 401은 전송 키, 400은 패킷/좌표/GPS ERR, 502는 저장소 오류입니다.
7. 지도: https://lte-gps-map.vercel.app/?device=l450061222243141
8. 이력: https://lte-gps-map.vercel.app/history.html — 장치 ID와 기존 관리자 인증키를 입력합니다.

AT+HTTP_SEND의 인자/따옴표 규칙은 펌웨어 문서를 기준으로 적용합니다. HTTPS 인증서 검증을 사용하며 기존 예시의 -k는 권장하지 않습니다. 실제 단말기에서 전송 성공 여부를 확인해야 합니다.

## 저장 및 조회

- 첫 필드가 장치 ID, LAT/LON이 WGS84 십진수 좌표입니다. ERR이 0이 아니면 저장하지 않습니다. TEST=1도 테스트 위치로 저장되므로 실제 장치 ID로 시험하면 실제 이력에 포함됩니다.
- 인증된 좌표가 들어올 때마다 최신 좌표와 이력을 함께 Redis 트랜잭션으로 저장합니다. 서버 수신 시각(UTC ISO)을 기록하고 화면에는 브라우저 현지 시각으로 표시합니다. KST는 단말기 제공 필드로 읽지만 별도 기록하지 않습니다.
- 장치별 최근 10,000건을 보관하고 초과분은 오래된 순으로 삭제합니다. 30초 전송 기준 약 3.47일 분량입니다. 과거 덮어쓴 좌표는 복구되지 않습니다.
- 최신 지도와 이력 화면은 응답 완료 후 30초 간격으로 조회합니다. 통신 지연에 따라 간격이 늘어날 수 있습니다. 새 데이터가 없으면 마지막 위치와 수신 시각이 유지됩니다.
- 이력은 관리자 인증 후 500건씩 조회합니다. 최신 화면은 자동 갱신, 이전 페이지 조회 중에는 자동 갱신을 멈춥니다. ‘조회 시작’으로 최신 화면으로 돌아옵니다.
- CSV는 현재 조회 중인 최대 500건을 내려받습니다. 영구 보관이 필요하면 별도로 저장하세요.
- 일반 방문자의 동의 기반 휴대전화 공유(5초, 최근 위치 24시간)는 기존 동작을 유지합니다. 이 문서의 이력 저장은 GPS 전송 키로 인증하는 단말기 위치 API에 적용됩니다.
